## Project Description
This project simulates how people make biased or irrational economic decisions under pressure or uncertainty. Drawing from behavioral economics, the simulator will present interactive decision-making scenarios that demonstrate common cognitive biases such as anchoring, loss aversion, and the sunk cost fallacy. 

Each scenario will provide users with choices and compare their decisions to the rational baseline. The goal is to reveal how subtle framing or context can lead to deviations from expected economic behavior. The project will model these scenarios with randomization, visualizations, and payoff analysis.

The simulator will include 3–4 decision scenarios, each tied to a specific bias. It will present randomized conditions, accept user choices, and visualize the outcomes vs the optimal choice.

## Requirements 
- Jupyter Notebook
- `dict` and `lists`: to store scenarios, outcomes, and user responses
- `random`: to introduce variability in each simulation
- `functions`: to modularize the scenarios
- `conditionals`: to compare user choice to rational choice
- `matplotlib`: to visualize outcomes

## Milestones 
- Milestone 1: Design and implement 2–3 behavioral scenarios using functions and random logic (e.g., anchoring, loss aversion). Each scenario will output options, take user input, and log decisions.
- Milestone 2: Create visualizations (payoff comparisons, bar charts of user choices vs rational options). 
- Milestone 3: Finalize and publish.
